## ✨ Sobre o repositório

Este repositório reúne arquivos da atividade de **vetores e matrizes**, desenvolvida durante o **Bootcamp de Analista de Dados da Generation Brasil**.

O objetivo é praticar fundamentos de programação, exercitando a criação, o acesso e a manipulação de conjuntos de valores. Esses conceitos ajudam a desenvolver o raciocínio lógico e são úteis para trabalhar com dados de forma estruturada.

## 🎯 Objetivos de aprendizagem

- Compreender como valores podem ser organizados em vetores e matrizes.
- Praticar o acesso e a manipulação de elementos por posição.
- Desenvolver o raciocínio lógico na resolução de exercícios.
- Reforçar a organização e a leitura do código.

## 🧠 Conceitos estudados

| Conceito | Descrição |
| --- | --- |
| **Vetores** | Estruturas que organizam uma sequência de valores. |
| **Matrizes** | Estruturas que organizam valores em linhas e colunas. |
| **Índices** | Posições usadas para acessar elementos de uma estrutura. |
| **Lógica de programação** | Aplicação de etapas e operações para resolver problemas. |
